# Kelsey's Interior Design Exam Notes

Notes on *Interior Construction & Detailing* (Ballast, 6th ed.). Covers Ch 1 (Partitions), Ch 2 (Ceilings), Ch 5 (Glazing), and Ch 16 Lighting (16-11 to 16-19, plus the start of Plumbing).

- **Kelsey-Exam-Study-Guide.pdf**: the file to study from. Page 1 is the one-page must-know summary. After that come key terms, main points, and tables for each chapter, with a numbers cheat sheet at the end.
- **detailed-notes.md**: longer page-by-page notes, for looking up specifics.
- **study-guide.html**: the source file for the PDF.
